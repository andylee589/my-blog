# 你好，世界！

欢迎来到我的博客！这是我使用 Next.js 搭建的个人小站的第一篇文章。

## 为什么要写博客？

写博客有很多好处：

1. **记录学习过程** - 把学到的知识写下来，加深理解
2. **分享与交流** - 与他人分享经验，互相学习
3. **个人品牌** - 展示自己的技术能力和思考

## 这个博客的特点

这个博客具有以下功能：

- **暗色模式** - 支持亮色/暗色主题切换，保护眼睛
- **MDX 支持** - 可以在 Markdown 中使用 React 组件
- **响应式设计** - 适配各种屏幕尺寸，移动端友好
- **RSS 订阅** - 支持 RSS 订阅，方便读者关注更新
